# Submission Rules

## Required Artifacts

| Artifact          | Format          | Gate                                           |
| ----------------- | --------------- | ---------------------------------------------- |
| Idea Submission   | PDF only        | under 25 MB and based on the provided template |
| Innovation Canvas | JPG or PNG only | one page, A3 portrait only                     |

Optional supporting materials may include apps or videos. They do not replace either required artifact.

## Idea Submission Sections

The PDF must cover:

1. Team Information
2. 1 The Problem
3. 2 Target User
4. 3 Your Solution
5. 4 Innovation Element
6. 5 Impact
7. 6 Feasibility
8. 7 Visual Concept
9. 8 Why Your Team Should Win, 100 words or less

Do not assume a special file name because none is stated in the supplied ground truth. Use a clear team-specific name after the team name is decided, and verify the uploaded file itself.

## Innovation Canvas Pillars

1. The Concept
2. Problem
3. Target User
4. Innovation
5. Impact

The final canvas must be one A3 portrait page in JPG or PNG. A PDF canvas does not meet the stated format.

## Submission Channel

- Submit all materials through the Kolaxus platform.
- Email submissions are not accepted.
- The deadline is 21 August 2026 at 11:59 PM.
- No extension will be given.

## Format Verification

Check the exported artifacts, not only the editable source files:

- confirm the idea file opens as a PDF;
- record its observed file size and verify it is under 25 MB;
- confirm the canvas file opens as JPG or PNG;
- confirm the canvas is portrait and designed at A3;
- confirm the canvas is one page or image;
- confirm Section 8 is 100 words or less;
- confirm the intended files are attached in Kolaxus.

Use `../submission/preflight.md` for the signed final check.

## Source Boundary

Primary sources live under `../source/`. That directory is an immutable record. Never edit, move, rename, reformat, or delete anything there.
