# Official SDG Icons

Unmodified artwork for the two goals recorded in `docs/decisions.md`.

| File            | Goal                                           | Official Colour |
| --------------- | ---------------------------------------------- | --------------- |
| `E-Goal-01.png` | SDG 1, No Poverty                              | `#E5243B`       |
| `E-Goal-16.png` | SDG 16, Peace, Justice and Strong Institutions | `#00689D`       |

**Source:** United Nations, "Communications Materials",
<https://www.un.org/sustainabledevelopment/news/communications-material/>, downloaded 20 August 2026. Originals are 1500x1500 PNG.

**Permission basis:** the UN's guidelines state that permission is not required for uses that are
primarily illustrative. See
<https://www.un.org/sustainabledevelopment/wp-content/uploads/2023/09/E_SDG_Guidelines_Sep20238.pdf>.

**Do not alter these files.** The guidelines forbid modifying the icons, so they are rendered at
their natural aspect ratio with no recolouring, cropping or corner rounding.

**Do not use the SDG logo carrying the UN emblem.** That variant is restricted to UN System
partners. These individual goal icons are not.

The same two files serve the deck (#9) and the A3 canvas (#13). Canva also ships the official set
if that is easier than copying from here.
